# Auto Clicker

The auto clicker currently shares the desktop renderer and Python input engine.

Canonical source:

- `../../apps/click-interval/backend.py` — click scheduler and native input
- `../../apps/click-interval/renderer.js` — controls and state
- `../../apps/click-interval/index.html` — interface
- `../../apps/click-interval/main.js` and `preload.js` — desktop IPC

The standalone two-tool release is in `../../editions/auto-macro`.
