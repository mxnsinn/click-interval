# Privacy policy

Click Interval is a local desktop toolbox. Settings, macros, click profiles,
server configuration, server worlds, player records, and imported add-ons stay
on the user's computer unless the user deliberately shares or publishes them.

The application may make network requests for:

- signed update manifests and release files;
- Minecraft server software and add-ons selected by the user;
- public Minecraft profile, skin, and add-on metadata;
- optional server networking and voice-chat features configured by the user.

Click Interval does not include analytics or advertising SDKs. The project does
not intentionally collect macros, input events, server worlds, player chat,
filenames, or device identifiers. Public release artifacts do not contain the
maintainer's private keys, tokens, local settings, logs, macros, or server data.

Security reports should follow [SECURITY.md](SECURITY.md).
