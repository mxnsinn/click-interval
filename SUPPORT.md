# Support

Use the [support form](https://click-interval.netlify.app/support.html) for help
with installation or use. Use GitHub Issues for reproducible public bugs and
feature requests.

Report security vulnerabilities through
[GitHub private vulnerability reporting](https://github.com/mxnsinn/click-interval/security/advisories/new).
Do not publish private macros, server worlds, tokens, personal information, or
security-sensitive reproduction details in an issue.
